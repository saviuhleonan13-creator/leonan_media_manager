# Avaliação prática · EP04

Preencher pelo operador com arquivos reais. **Ainda não realizada nesta entrega.** O piloto sintético valida o funcionamento, não o ganho de produtividade.

## Sessão curta

1. Separe três takes conhecidos, incluindo uma versão corrigida e, se houver, uma imagem reutilizada de propósito. Preserve as pastas originais.
2. Na organização atual, procure a imagem e o vídeo corretos de cada take. Anote o tempo e as dúvidas. Depois importe os mesmos materiais no aplicativo e anote o tempo de organização inicial separadamente.
3. Faça as mesmas buscas no aplicativo, idealmente em outra ordem. Confira o nome original, amplie as âncoras e reproduza os vídeos para confirmar que são os pares corretos.
4. Troque uma versão, volte à anterior e confirme que o take exige nova decisão. Reutilize uma imagem intencionalmente e confira o aviso sem descartá-la automaticamente.
5. Exporte o ZIP e restaure em uma pasta de dados nova. Confirme os pares, versões, prompts e decisões.

Não gerar novos vídeos para este teste. Para reduzir o efeito de memória, alterne a ordem das buscas ou repita em outra sessão.

## Decisão sobre a V0.1

- [ ] O operador encontra o par correto sem procurar nas pastas originais.
- [ ] Versão desconhecida fica evidente e não parece aprovada.
- [ ] Uma troca de mídia exige nova decisão.
- [ ] Reutilização intencional não impede o trabalho.
- [ ] Exportação e restauração preservam as mídias e o registro.
- [ ] O tempo de uso e o risco de erro compensam o esforço inicial de organizar.

Se algum ponto falhar, registrar o problema e corrigir o fluxo essencial antes de expandir. Se os três takes passarem, repetir com os 7–9 takes do EP04. O operador decide se o ganho justifica continuar.
