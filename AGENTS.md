# Production Engine — regras para agentes

- Trabalhe em branch experimental; nunca modifique dados de producao.
- Nao altere a pasta data/, backups, SQLite ou midias originais.
- Os documentos oficiais da serie sao privados e externos a este repositorio publico.
- Nao copie personagens, roteiros, prompts internos completos ou arquivos privados para GitHub publico.
- Teste com dados sinteticos; alteracoes de media precisam de revisao humana.
- Nao gaste creditos de plataforma nem publique conteudo autonomamente.
- Nao mude falas literais nem faca decisoes criativas sem aprovacao do operador.
